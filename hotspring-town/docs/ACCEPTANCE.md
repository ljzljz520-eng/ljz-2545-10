# 验收指南

## 一键验收

```bash
# 终端1
npm start
# 终端2
npm test && npm run acceptance
```

- `npm test`：23→24 项 node:test（引擎纯函数 14 + Express+pg-mem API 9 + 真实 PG 集成另计）。
- `npm run acceptance`：49 项端到端 HTTP 检查（`scripts/acceptance.py`，仅用标准库）。
- `npm run test:pg`：真实 PostgreSQL 冒烟（需要 `DATABASE_URL`）。

## 手工场景对照（需求 → 操作）

| 验收点 | 操作 | 预期 |
|---|---|---|
| 地图筛选 | 勾选住宿/餐饮、亲子、步行圈 | 地图实时过滤；侧栏列出每个隐藏地点及原因 |
| 部分泡池检修不连坐 | 日期选 2026-10-06，查看「霧見湯」 | 大露天不可用；食事処/客室仍可用；场馆虚线提示 |
| 推荐展开到设施 | 「おすすめ」页签 | 每张卡片列出具体设施及当日可用性，可直接「追加」 |
| 泉质描述+来源 | 点地图标记→设施 | 泉质原文/受控词/来源/免责；もみじ館提示链接失效待核 |
| 时间段组合 | 「マイプラン」勾选设施→组合 | 返回各设施时段与最早串联 |
| 锁定保留+解释冲突 | 加点→锁定 16:00→管理改周日时窗→部分修复 | 锁定点时刻不变、标红说明“営業時間外”，不被换点 |
| 完整 vs 局部一致 | 点“部分修復” | 绿条显示 reused/affected，`full_equivalence=true` |
| 跨日维护 | 2026-10-05 22:00→10-07 10:00 | 10-06 全天不可用、10-07 恢复 |
| 链接失效 | 管理页→“リンクを再核查” | もみじ館旧页 404 broken，相关信息降级待核 |
| 地点合并 | 管理页选两点→統合 | 旧 id 重定向、设施迁移、地图不再显示旧点 |
| 过期离线包 | 发“期限切れパック” | expired 横幅、只读；新包 usable |
| 双设备编辑 | 顶栏切到スマホB后用旧版保存 | 409 + 当前版本提示，不静默覆盖 |

注入时间（复现跨日判定）：`SERVER_NOW=2026-10-01T04:00:00Z npm start`（= JST 13:00）。
