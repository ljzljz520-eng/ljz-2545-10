验收场景与站内设计说明

① 维护（含跨日）与“不连坐”

汤本馆·露天桧木池安排了 2026-10-05 20:00 → 10-07 09:00 的跨日检修； 同馆汤上食堂、以及全町住宿不受影响。

② 链接失效

来源 #3（樱见食堂旧页）巡检为 HTTP 410；系统把来源标记为 dead 并保留巡检记录。



      
③ 地点合并

      
旧「樱见食堂」已并入「峰味食堂」：设施、别名、步行边、行程引用全部迁移，旧点 301 式指向保留点。

      

      


      
④ 过期离线包

      
2026.07 包已过期时，客户端必须收到明确的 expired 状态而不是静默使用旧数据。

      

      


      
⑤ 两台设备编辑同一行程

      
设备 B 若带着旧版本号提交，会收到 409 冲突，编辑保留待处理，服务端绝不覆盖设备 A 的修改。

      

      


      
⑥ 锁定后开放时间变化

      
锁定行程点后修改设施开放时间：锁定保留，行程页面解释冲突，不偷偷换点。

      

      


      
⑦ 完整重算 vs 局部修复一致性

      

      


      
⑧ 泉质：有来源的描述，不作医疗推断

      
所有泉质信息都挂接来源、检测日期，并固定附下述声明：

      
泉质条目仅为带来源的观测性描述（温度、pH、泉质类型、观感），
        不构成任何医疗功效承诺或治疗建议；入库即禁止疗效断言词。


      
站内原创设计说明「湯けむり · 五感散步」

      
视觉取色来自温泉现场：桧木绿（步道与林坡）、藏青蓝（夜汤与溪面）、
        朱印红（关键操作与冲突警示）、米纸底配粗界的和纸卡片。
        信息层级遵循“先设施、后场馆”：地图点选后第一层即具体泡池/楼层，
        凡不可用单元单独置灰并写明原因，从不让兄弟设施连坐。
        待核信息使用「核」印戳样式与正式数据严格区分；冲突用红印签说明，语气是解释而非替用户决定。
        原创主题三段：晨雾逐汤 / 泡泡亲子半日 / 夜蒸小吃线，文案与动线均为本产品原创。
